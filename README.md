# mipt-py-scrapper

Проект с ДЗ по питону по web scrapping.

Содержит скрипт [`scrapper.py`](scrapper.py), который осуществляет проход по всем страницам каталога с книгами (https://books.toscrape.com), парсит данные о каждой книге и сохраняет в файл.

## Запуск

1. Установка зависимостей:

```sh
pip install -r requirements.txt
```

2. Запуск python скрипта:

```sh
python scrapper.py
```

Полный список используемых зависимостей содержится в [`requirements.txt`](requirements.txt).
